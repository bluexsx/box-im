# 盒子IM Web (Vue3)

开源版即时通讯 Web 客户端，基于 Vue3 + TypeScript + Element Plus + Vite。

## 环境要求

- Node.js >= 18

## 安装依赖

```bash
npm install
```

## 本地开发

```bash
npm run dev
```

默认访问 http://localhost:8080 ，接口代理到 `http://127.0.0.1:8888`。

## 打包

```bash
npm run build
```

## 其他脚本

```bash
npm run preview
npm run lint
npm run prettier
npm run format:check
```
